# 福緣員工訂單系統

入口：<https://evil-deny.github.io/order/>。

保留原本「訂購／出貨／退貨」三分頁、大名與備註、客製化品項、訂購明細、揀貨、部分出貨、退貨數量與結案流程。只有商品清單套用顧客版的卡片尺寸、圖片、字級、數量控制及響應式排版；CSS 限定在 `#productList`，不影響其他畫面。員工頁不提供商品管理後台入口。

依店家要求，訂購、全部訂單讀取、出貨、退貨與客製化開單均免登入。公開 `/api/staff/orders` 提供訂單操作；任何取得網址的人都可看到訂單與聯絡資料並處理出貨／退貨。商品價格、庫存設定、分析及備份仍須從 backstage 管理員登入。

目錄使用 `channel=order` 的批發價與顯示狀態，與顧客共用庫存；每 15 秒與切回頁面更新。送單時檢查價格、供貨、庫存並預留數量。重送相同 requestId 不重複扣庫存。歷史商品名稱與成交價維持快照，部分出貨、取消及退貨均同步共用資料庫。

原瀏覽器 localStorage 資料未清除、未自動匯入。`index.html` 為 GitHub Pages 發布來源，`outputs/index.html` 為相同內容輸出。舊 `work/` 產頁腳本僅供歷史參考；請勿覆蓋新頁面。`node work/check_html.js index.html` 檢查模組語法。

畫面使用簡短單號與訂購來源色彩標籤；完整訂單 ID 保留於資料和操作請求。切入出貨／退貨會立即重讀所有來源訂單，也可按「更新訂單」。顧客同瀏覽器送單後會通知員工分頁更新；不同裝置仍每 15 秒更新。初次讀取失敗可直接按更新重試。


商品支援獨立的批發單位（`orderUnit`）與顧客單位（`customerUnit`），舊商品預設為「件」。公開商品依入口只回傳該入口的 `price` 與 `unit`。新訂單保存價格與單位快照，出貨與退貨沿用原單位；分析依商品與單位分列。單位是販售標示，共用庫存仍按數量扣除，不會自動換算箱／包。後台點擊商品縮圖可放大，支援關閉按鈕與 Esc。

新增商品使用伺服器分配的連續固定編號（p198、p199…），隱藏商品仍保留編號，既有商品與歷史單據不改號。目錄共用 catalog-order.js，依冷凍／冷藏／乾貨、既有類別順序、中文商品名稱（含數字自然排序）排列；新增或修改分類後自動排入，新增類別排在既有類別之後。
