# 福緣員工訂購

入口：<https://evil-deny.github.io/order/>。

員工免登入即可瀏覽與送單。畫面沿用顧客訂購的商品卡片、搜尋／分類、數量調整、確認明細、本機最近 30 張明細、複製與 LINE 聯絡流程。電話可選填。頁面不包含管理後台入口、所有訂單清單、出貨或退貨功能。

商品讀取共用 API 的 `channel=order` 目錄，使用後台設定的員工價與員工顯示狀態；可售庫存與顧客共用。每 20 秒、切回頁面或按更新商品同步。送單時伺服器再次驗證員工價、顯示狀態及庫存，並預留數量；相同訂單重送不重複扣庫存。

管理員請由 <https://evil-deny.github.io/backstage/> 登入處理全部訂單、出貨、退貨及分析。免登入員工入口不驗證員工身份，任何取得網址的人都能查看員工價及以員工來源送單；不能查詢其他人的訂單或修改商品。

新頁面的購物車與本機明細使用獨立 `fuyuan-staff-storefront-v1` 儲存鍵。舊版開單、出貨與退貨資料仍保留於原瀏覽器，未刪除、未自動匯入。雲端歷史訂單仍可在管理後台查閱。

`index.html` 為 GitHub Pages 發布來源，`outputs/index.html` 為相同內容的輸出版本。舊版 `work/` 產頁腳本屬歷史工具，請勿用它們覆蓋新頁面。`node work/check_html.js index.html` 可檢查模組語法。
